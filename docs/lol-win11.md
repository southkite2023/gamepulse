# 英雄联盟：Win11 本地识别原型

状态：本机浏览器原型，不是 Windows 安装包，尚未完成 Win11 实战验收。首个目标是“对局已找到／接受”弹窗；玩家仍在电脑上手动接受，不提供远程接受或自动点击。

## 当前能力

- Edge/Chrome 经用户点击授权采集游戏窗口，不读取游戏进程或客户端私有接口。
- 用户拖动框选整个客户端内容，将画面归一化到 640×324。
- 对文字和接受按钮两个区域分别计算灰度结构相关性，以较低分作为联合分数；不是 OCR，不理解文字语义。
- 分数至少 0.90、连续三个新采集样本通过后产生一条事件，每轮只提醒一次。每 250 ms 检查一次；不同浏览器负载下不保证固定延迟。
- 仅事件元数据离开本机。图像、截图预演和特征提取在浏览器本地进行。
- 共享终止、页面隐藏、超过 3 秒没有新画面会暂停监控。重设选区也会停止；必须手动重新开始下一轮。

## 参考画面与证据边界

正样本为用户于 2026-10-29 提供的 640×324 截图。代码库只保存中央文字与按钮区域的灰度描述符，不保存完整截图或好友栏。浏览器导入原始截图预演得到 100% 参考相似度，这只是同源回放检查，不能视为对未知画面的识别准确率。

## 在 Windows 上试用

需要 Node.js 24+、Git，以及 Windows 自带 OpenSSH 客户端。获取包含本功能的 `feat/lol-visual-console` 分支：

```powershell
git clone --single-branch --branch feat/lol-visual-console https://github.com/southkite2023/gamepulse.git
cd gamepulse
Copy-Item .env.example .env
notepad .env
```

只在 Windows 的本地 `.env` 设置：

```text
GAMEPULSE_PUBLISHER_TOKEN=服务器已有的发布凭证
GAMEPULSE_RELAY_URL=http://127.0.0.1:18788
```

不要复制 AppSecret。发布凭证只适用于当前开发者单设备联调，不能共享给公开用户。

另开一个 PowerShell，建立仅绑定本机的 SSH 转发（使用你平时登录这台服务器的账号和地址；以下是域名指向同一服务器时的示例）：

```powershell
ssh -N -L 127.0.0.1:18788:127.0.0.1:8788 root@yuashie.cn
```

由本人完成 SSH 登录，不要上传密码或私钥。保持通道终端打开。此开发方案复用已有服务器访问权限，不需要将 `/v1/*` 暴露公网，也不要修改已有 Nginx 配置。

在项目终端运行：

```powershell
npm test
npm run desktop
```

用 Edge 打开 `http://127.0.0.1:8790`（必须用此地址，不能双击 HTML 文件）。

1. 先用“截图预演”导入已有接受弹窗截图，验证参考模板；此操作不发通知。
2. 选择英雄联盟客户端窗口，确认预览包含整个客户端；若含桌面或窗口边框，框选客户端完整内容。
3. 保持页面可见、客户端不最小化，点击“开始本轮监控”。浏览器不要切到其他标签或最小化；可将控制台与客户端并排放置。
4. 手机锁屏，实际排队出现接受弹窗时观察是否及时收到；人保持在电脑附近并手动接受。不要为收集样本故意错过接受。
5. 每次新一轮匹配，重新点击开始；已经发出或状态未知的通知不会自动重发。

服务器重启会丢失当前微信绑定；需要按微信接入指南重新绑定。如果提醒报 gateway_http_409，先检查是否还绑定、是否有其他操作正在发送。网络超时可能已送达，应先检查手机。

## 尚需验证和完善

- 最小化/遮挡/切后台时的采集表现，及原生 Windows 后台采集方案。
- 实测误报、漏报、端到端时延与微信锁屏提示；目前没有实战测量数据。
- 安装包、绑定 UI、持久化、多用户凭证与设备隔离。当前配置不能作为面向公众的正式版。
