# 第一版发布计划

目标日期：2026-11-05（北京时间），不指定具体时刻。只有通过验收且微信正式账号权限已就绪才公开发布；如果外部审核未完成，当天完成发布检查并说明阻碍，不承诺自动上线。

## 顺序与验收

1. 微信测试号直发：配置本地凭证和测试模板，实测手机后台与锁屏提醒。验收以手机收到为准。
2. 扫码绑定：校验回调、临时二维码、过期和取消关注；实测关注前后两种扫码路径。
3. Win11 识别：先选一款游戏，手动选区 + 本地模板匹配，验证分辨率缩放、遮挡、动画和连续匹配；不注入进程、不读取游戏内存。
4. 接入和稳定性：接上微信适配器，实测网络中断、超时、重复事件、延迟与误报。完成按用户鉴权、限流、持久化和密钥安全存储。
5. 安装与操作：Windows 安装/启动、选区、绑定、测试通知、开始/停止监控和解绑；提供清晰错误提示。
6. 正式号切换：账号资格、认证、合适模板与接口权限确认后，适配模板、重新绑定和复测；测试号凭证不得出现在公开包中。
7. 发布：确认隐私说明、开源依赖、CI、回退路径及试用反馈渠道，发布可追踪版本。未通过前不称为正式可用。

## 用户需准备

- 微信测试号：本人登录、关注测试号、新建测试模板；密钥仅填本地 `.env`。
- 首个验证游戏名称与“正在匹配/匹配成功”的画面样本。
- 可用于 Win11 实测的电脑。
- 正式服务号的申请主体与后台可用权限；不要仅依据注销冻结期推断可用日期。
- 开发回调可用的 HTTPS 地址；正式运行时需要持续在线的后台，具体部署资源另行确认。

当前未设置自动部署或定时后台开发。阶段完成情况以 PR、测试和实机记录为准。
